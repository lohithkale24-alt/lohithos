LohithOS (x86 32-bit Bare-Metal OS)

A genuine custom operating system built from scratch in C and Assembly. Featuring a VBE linear framebuffer desktop GUI, Intel PRO/1000 network driver, TCP/IP stack, Virtual Filesystem, and interactive games.

🖥️ Core Architecture

  • Architecture: x86 32-bit Protected Mode (i686 freestanding)
  • Kernel: 100% Custom Monolithic (Freestanding C & ASM)
  • Display: VBE Linear Framebuffer 1024x768 @ 32bpp TrueColor
  • Compositor: Double-buffered backbuffer (flicker-free)
  • Memory: 8 MB Dynamic Heap (kmalloc / kfree)
  • Interrupts: 256-gate IDT, PIC 8259 remap, 100 Hz PIT timer

🌐 Hardware & Networking

  • Network Card: Intel PRO/1000 MT Desktop (82540EM / e1000)
  • Protocols: Ethernet II, ARP, IPv4, ICMP Echo (ping), UDP, DHCP
  • Wi-Fi Support: Bridged via VirtualBox NAT to Host Wi-Fi
  • Input: PS/2 Keyboard & PS/2 Streaming Mouse
  • Storage: In-memory Virtual Filesystem (VFS)
